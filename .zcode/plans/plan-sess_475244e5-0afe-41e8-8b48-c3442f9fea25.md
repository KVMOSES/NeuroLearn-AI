# NeuroLearn Premium Redesign + PDF Delete

Full transformation across all 13 views, foundation-first. Elevate the existing oklch dual-theme by injecting neon/glass/glow into **both** light and dark (no dark-only reset). Remove decorative emojis from UI (buttons, headers, titles, badges, copy) while **keeping** companion avatars/personalities (Nova/Atlas/Sage/Spark). Preserve all functionality, API contracts, routes, and auth. Add framer-motion-based premium interactions (cursor spotlight, magnetic buttons, card tilt) — all gated behind `prefers-reduced-motion` and disabled on touch.

**No new runtime dependencies** — `framer-motion`, `lucide-react`, `sonner`, `@vercel/blob`, `recharts` are all already installed.

## Phase 0 — Backend: make PDF delete work end-to-end (fixes a regression)

The Blob migration stored `storagePath = blob.url`, but two handlers still hit the local FS.

- **`src/lib/documents.ts`** — `readDocumentBytes()`: detect URL (`http://`/`https://`), `fetch()` the bytes and return the Buffer; fall back to local `fs.readFile` for legacy rows. Keeps preview/download working.
- **`src/app/api/documents/[id]/route.ts`** — `DELETE`: import `del` from `@vercel/blob`; when `storagePath` is a URL, `await del(storagePath)` (try/catch, never fail the request on blob errors); else legacy `fs.unlink`. Prisma cascade already removes chunks/flashcards/quizzes/topics/skills. Return a richer payload `{ deleted: true, title }` for the optimistic UI.
- Verify: upload → list → preview/download → delete all work against Blob.
